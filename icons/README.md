# 图标文件说明

请在此目录下放置以下图标文件：

- `icon16.png` - 16x16 像素的图标
- `icon48.png` - 48x48 像素的图标  
- `icon128.png` - 128x128 像素的图标

如果没有图标文件，扩展仍然可以正常工作，但会在 Chrome 扩展管理页面显示默认图标。

您可以使用在线工具生成图标，例如：
- https://www.favicon-generator.org/
- https://realfavicongenerator.net/

或者使用任何图片编辑软件创建 16x16、48x48、128x128 像素的 PNG 图片。
